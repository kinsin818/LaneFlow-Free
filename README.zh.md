# LaneFlow Free（中文说明）

给代理 IP 用户的最笨 UI——没有订阅、没有节点、没有规则表；手动填 IP，选个程序，点开关，完事。

LaneFlow Free 在你**已有代理出口环境**（任何第三方 TUN / VPN 客户端）之上做**二次分流**：把指定进程的流量经你填的代理出口 IP 出口，未指定的进程流量走原路不受影响（其 DNS 查询会被接管解析，但解析不经专用出口、流量仍走原路，见下方能力边界）。它**不替代你已有的代理客户端**，只是其上的一个开关。

## 用法

1. 出口配置：选类型（Socks5 / HTTP），填主机（支持 `1.2.3.4:1080` 或 `socks5://user:pass@host:port` 自动拆字段）、端口、账号密码（可选、须成对）。点「代理检测」验证可达。
2. 进程绑定：刷新列表 → 选一个应用 → 「绑定并启用」。再次绑定会自动替换上一个。同名多实例会被拦下，需先关其余。
3. 停用：点「停用」即停掉内核、撤掉虚拟网卡、恢复直连。关闭软件同样复原。

## 能力边界（重要）

- **仅承诺按应用分流 TCP**：被绑应用的 TCP 流量走你填的代理 IP 出口；未绑应用走原路。
- **UDP / QUIC 为非承诺流量**：默认**拦截兜底**（内置 reject 规则），**不保证**经专用出口。能否自动回落 TCP 取决于具体应用，免费版未逐一实测、**不作承诺**。这是免费版的明确范围，不是缺陷。
- **域名解析**：绑定态下，被绑应用的 DNS（53 端口）由 LaneFlow 接管解析（上游为公共 DoH 解析器 `223.5.5.5`，直连查询、**不经专用出口**）；仅其 TCP 连接走专用出口。停用后 DNS 恢复系统原样（DHCP 型接口交回 DHCP，不再固化静态值）。
- 单出口、单绑定、无规则引擎、无导入导出、不留存日志、无云同步。
- **关于 LaneFlow.pdb**：包内有意附带 PDB 调试符号——崩溃报告可读（显示函数名/行号而非裸地址）。源码本就全部公开于本仓库，符号不含源码之外的任何信息。
- **重启行为**：接管生效期间写入的是持久化静态 DNS。若在接管态直接重启机器（或进程被强杀）且 LaneFlow 未运行，系统 DNS 会停留在（已不存在的）TUN 地址上、解析失败，直到再次启动 LaneFlow——启动时会检测残留接管并自动还原。正常关闭应用则总是立即还原。

## 四条声明

1. 启用 / 停用瞬间可能有 **1–2 秒断流**（虚拟网卡与路由切换）。
2. 代理**账号密码以明文**保存在本机 `%APPDATA%\LaneFlow\settings.json`，请仅在信任的机器上使用。
3. 免费版**只按应用分流 TCP**；UDP / QUIC 默认拦截，不在承诺范围。
4. 本软件**不收集任何数据**、不含遥测、不联网自更新。

## 架构

- 壳：.NET 8 Windows Desktop（WPF）。
- 内核：随包分发的 [sing-box](https://github.com/SagerNet/sing-box) v1.14.3（GPL-3.0），以 TUN 接管被绑应用流量并路由到你的代理。内核版本与校验值见 `core/VERSION.txt`、`core/SHA256SUMS.txt`、`LICENSE/sing-box.txt`。
- 配置：用户配置 `%APPDATA%\LaneFlow\settings.json` → 运行时渲染生成 `%APPDATA%\LaneFlow\singbox\config.json` 交由 sing-box 使用。
